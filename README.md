# Practical Programming in Chemistry (CH-200)

This fork repository is aiming to solve virtual environment's challenges associated with Anaconda by transitioning to UV and/or PIXI project and environment management tools for the tutorials of the course "Practical Programming in Chemistry", taught at EPFL by Prof. Philippe Schwaller.

This content of the course is an introduction to computer programming, focusing on chemistry applications. It is targetted to students having a background in chemistry, but very few knowledge in programming.
